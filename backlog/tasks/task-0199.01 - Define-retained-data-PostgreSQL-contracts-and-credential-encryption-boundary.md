## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Inventory the retained MongoDB data and its consumers, then fix the PostgreSQL target schema, credential-encryption boundary, and backfill contract before implementation.

Cover calendar connections, provider tokens, sub-calendars, calendar preferences, and OAuth origin from the retained `users` document; `otpCodes`; `dailyuserlogs`; event-creator analytics; and friend-request retirement.
Specify the encrypted-at-rest credential boundary using the existing `ENCRYPTION_KEY` AES-GCM helper, and which credential fields are encrypted.
Specify ledger-based backfill that resolves owners through platform_identities.external_user_id and keeps source documents intact.
Define the sequencing and rollback boundaries for removing the retained MongoDB account document, MongoDB runtime, driver, Compose and environment configuration, and collections.
Record durable decisions as indexed ADRs and canonical requirements, following the requirements authoring instructions.

This task is documentation and canonical-requirement authoring only; it adds no runtime code, schema, or migration tooling.
