## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Remove the last retained MongoDB account usage and retire the dormant friend-request storage.

Delete the `friendrequests` model, accessor helpers, collection variable, and account-deletion coverage instead of migrating it.
Remove the retained MongoDB `users` document reads and writes: the `GetUserById` MongoDB fallback, `EnsureIntegrationDocument`, the account/integration overlay in middleware, and `UpdateUserIntegrationFields` once calendar, OTP, and daily-log data are PostgreSQL-authoritative.
Collapse account deletion so it no longer depends on a MongoDB cleanup step.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The friendrequests collection, model, and accessor helpers are removed, and no runtime code references them.
- [ ] #2 The retained MongoDB users document is no longer read or written at runtime: the GetUserById MongoDB fallback, EnsureIntegrationDocument, the integration overlay, and UpdateUserIntegrationFields are removed or replaced by PostgreSQL-only paths.
- [ ] #3 Account deletion removes all retained data through PostgreSQL and no longer calls the MongoDB cleanup step.
- [ ] #4 Existing unit and route suites pass with a single authoritative store for accounts, calendar, OTP, and daily logs.
