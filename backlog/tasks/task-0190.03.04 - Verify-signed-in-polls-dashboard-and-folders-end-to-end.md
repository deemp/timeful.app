## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Added repo-tracked Firefox coverage that drives the real browser UI against the isolated test stack with PostgreSQL creation enabled.

Spec: e2e/specs/timed-event-postgres-dashboard-folders-firefox.spec.ts has four tests.
Test 1 signs in, creates a supported dates-only PostgreSQL poll, asserts the bare Crockford short id, asserts a live postgres_events row with is_deleted=false, sees the poll on /home with href /e/<shortId>, and confirms it survives a reload.
Test 2 creates a folder through the dashboard dialog, moves the poll into it through the EventItem Move to menu, polls GET /api/user/folders until the canonical event id is a member, reloads, and asserts the link renders inside that folder's data-folder-id container plus one folder_events row with event_id set.
Test 3 archives the poll from the dashboard menu, asserts is_archived=true in PostgreSQL and the Archived bucket, reloads, expands Archived to confirm the poll is only there, then deletes it from the dashboard and asserts the link is gone, is_deleted=true, and GET /api/events/<shortId> is 404.
Test 4 uses two isolated browser contexts (owner and stranger) to prove isolation: the owner sees the poll and folder; the stranger dashboard listing and page exclude both; folder GET/PATCH/DELETE are 404; and event archive, settings edit, and delete are 403.

Helper: e2e/helpers/postgres-inspect.ts resolves Playwright's randomized timeful-test-* database from server-test's POSTGRES_APPLICATION_URI and runs scalar psql queries on postgres-test, so inspections can never touch a development database.

No runtime code changed; the work is verification only.
