## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The account route tests leak platform identities, reuse fixed email fixtures, and mutate the router after the test server starts. The new account repository and backfill tests are also absent from the default isolated Compose test command, so CI can pass without running them. Make the account test suite isolated and rerunnable, and ensure the isolated stack runs the repository and backfill suites.
