## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The account route tests leak platform identities, reuse fixed email fixtures, and mutate the router after the test server starts. The new account repository and backfill tests are also absent from the default isolated Compose test command, so CI can pass without running them. Make the account test suite isolated and rerunnable, and ensure the isolated stack runs the repository and backfill suites.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Post-finalization verification found an additional in-scope leak: `server/scripts/20260910_mongo_accounts_to_postgres/main_integration_test.go` registered `defer mongoClient.Disconnect(ctx)` and `defer pool.Close()`, which run before `t.Cleanup`. The fixture cleanup therefore executed against a closed pool and silently deleted nothing, leaking 2 backfilled accounts and 2 platform identities per run. Replaced the defers with `t.Cleanup` (registered before the fixture cleanup so they run last) and made the fixture deletes surface errors. Verified the full default command three times against the retained DB with zero identity growth.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Made the account test suite isolated and rerunnable and wired the default isolated stack to run the account repository and backfill suites.

Changes:
- `server/routes/accounts_test.go`: the test-only `/test/account-contract/sign-in/:id` route registers inside `newAccountContractRouter`, before `httptest.NewServer`; `deleteAccountTestFixtures` deletes each created PostgreSQL account and its platform identity; `insertOtpCode` registers per-email OTP cleanup; the adoption test uses randomized email/calendar fixtures.
- `server/scripts/20260910_mongo_accounts_to_postgres/main_integration_test.go`: fixed a residual leak. `defer mongoClient.Disconnect(ctx)` and `defer pool.Close()` ran before `t.Cleanup`, so the fixture deletes executed against a closed pool and silently leaked 2 accounts and 2 platform identities per run. Disconnects are now `t.Cleanup` registered before the fixture cleanup (LIFO, so they run last), and fixture deletes report errors.
- `compose.test.yaml`: `server-route-test` default command is now `go test ./... -count=1`, so the `postgres` account repository suite and the `scripts/20260910_mongo_accounts_to_postgres` backfill suite run, matching the CI override.
- `AGENTS.md` and `docs/environments.md` describe the default command as the backend test suite.

Evidence:
- Removed stale backfill residue; baseline is 5 deterministic route-test platform identities.

- `go vet ./...`, `npm run format:markdown`, and `npm run format:markdown:check` pass.

No runtime, deployment, or browser-E2E surface changed, so browser E2E is not required for this chore (DoD#3 satisfied vacuously).
