Decomposed into four sequential subtasks: TASK-0190.05.01 PostgreSQL availability-group schema and repository (AC#1, AC#3 foundation), TASK-0190.05.02 group lifecycle, invitations, and reads (AC#1, AC#3), TASK-0190.05.03 group response mutation and calendar-derived availability (AC#2, AC#3), and TASK-0190.05.04 end-to-end verification (AC#4). This task stays open as the parent and is complete when all four subtasks and its acceptance criteria are satisfied.

Durable decisions recorded for the subtasks and for TASK-0190.06:
- Schema follows the contract targets event_attendees from server/docs/postgres-core-migration-contracts.md (Attendees And Invitations) plus an extended event-kind constraint admitting `group`; legacy Mongo attendee and event identifiers are rewritten to fresh PostgreSQL identities during TASK-0190.06, not preserved as a runtime map.
- Group responses reuse the existing postgres_event_responses table; calendar-derived mode, selected calendars, copied calendar preferences, and manual availability live in the response payload, and the manual availability window lives in the event payload. No second response table is introduced.
- Attendee membership is keyed by invitation email, preserves absent versus explicit false decline state, and resolves to a PostgreSQL account by email where one exists. Retained MongoDB calendar connections resolve through the explicit account mapping (platform_identities.external_user_id) so calendar-derived availability keeps working without making MongoDB a second account authority.
- Group creation reuses the existing POSTGRES_ANONYMOUS_EVENT_CREATION_ENABLED transition flag; no second flag is introduced, and removal stays in TASK-0190.07.
- Group response mutation reuses the explicit-selection and Event Visitor Control Credential authority contract from the anonymous event compatibility contract.
- TASK-0190.05.04 is the dedicated final verification subtask covering API and Firefox browser coverage; migrated fixture output remains owned by the TASK-0190.06 migration tooling.
