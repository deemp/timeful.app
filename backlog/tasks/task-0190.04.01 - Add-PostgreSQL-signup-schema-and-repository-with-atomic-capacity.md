## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement the PostgreSQL persistence layer for signup forms: the event_signup_blocks and event_signup_responses tables, the signup event-kind constraint, and the repository operations that back blocks and signup responses. Preserve block/response relations and enforce block capacity atomically. Do not add route behavior in this subtask.

Schema targets follow server/docs/postgres-core-migration-contracts.md (Signup Form Fields): legacy Mongo block identifiers and signup-response keys are rewritten to fresh PostgreSQL identities during TASK-0190.06, so this subtask builds the runtime target shapes rather than a legacy-identifier map. Capacity enforcement is new behavior required by that contract.
<!-- SECTION:DESCRIPTION:END -->

<!-- AC:BEGIN -->
