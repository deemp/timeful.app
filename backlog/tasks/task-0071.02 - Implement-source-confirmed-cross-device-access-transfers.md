## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement the approved PostgreSQL-only cross-device access behavior after TASK-0071 delivers Event Visitor Identity ownership, EVCC authority, opaque response selection, and blind-availability filtering. The event-page action continues access on another browser through a five-minute pending link, target-displayed matching code, and source approval. It transfers a normal signed-in platform session or a distinct Granted EVCC without changing source ownership. MongoDB behavior and credentials remain unchanged.
<!-- SECTION:DESCRIPTION:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Implemented source-confirmed cross-device access transfers for PostgreSQL events (TASK-0071.02, per ADR-010). The event page offers one Continue on another device action that creates a five-minute transfer with hashed browser proofs; the copied link opens a target page showing a matching code and grants no authority until the source approves that exact code. Signed-in transfers issue a normal authenticated session for the source Platform Identity; anonymous transfers prove the source EVCC (plus the Event Owner Edit Token for owners) and issue a distinct Granted EVCC preserving role powers without transferring ownership. Granted EVCCs stay valid until browser data is cleared or the source revokes them, and revoked credentials are rejected on use. When a grant-holding target signs in, app-level consent is required before associating the source Event Visitor Identity with the Platform Identity. Expired, cancelled, reused, code-mismatched, unapproved, unauthorized, account-changed, and revoked transfers are rejected, including concurrent single-redemption and session-save rollback guarantees. MongoDB persistence, request behavior, and credentials are unchanged (new routes use postgresEventRouteUnavailable for Mongo events). Validation: full frontend unit suite (143 files, 1050 tests) plus the later polling regression; frontend lint, formatting, typecheck, and build; E2E lint/typecheck; combined Firefox transfer/owner/identity/plugin run 10/10; full PostgreSQL repository and MongoDB+PostgreSQL route suites; final scoped TestPostgresAccessTransfers rerun including the source-account-change rejection; Swagger regenerated and frontend API types regenerated; compatibility documentation updated with user instructions and endpoint contracts. Implementation committed as b34a4b70; no deployment.
