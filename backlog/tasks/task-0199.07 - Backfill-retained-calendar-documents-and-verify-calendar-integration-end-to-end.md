## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Provide the resumable backfill and end-to-end verification for moving existing retained calendar integration data into PostgreSQL.

Add migration tooling that reads retained MongoDB `users` calendar documents and preferences, resolves owners through platform_identities.external_user_id, writes PostgreSQL calendar records with encrypted credentials, and records progress in the migration ledger without modifying MongoDB source data.
Add reconciliation for counts, enabled flags, sub-calendars, and preferences, including interruption and rerun coverage.
Verify the connect, refresh, toggle, and remove flows in an isolated stack and a Firefox e2e run.
