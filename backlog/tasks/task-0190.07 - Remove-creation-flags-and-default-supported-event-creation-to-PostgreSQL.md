## Summary

Removed the PostgreSQL anonymous-creation transition flags and made supported event creation default to PostgreSQL.

## What changed

- **Routing** (`server/routes/postgres_event_routes.go`, `server/routes/events.go`): replaced `postgresCreationEnabled` with `postgresSupportsEventCreation`, dropping the `POSTGRES_ANONYMOUS_EVENT_CREATION_ENABLED` env check. Supported kinds (timed, dates-only, dow, group, signup) now always route to `postgresCreateEvent`; unsupported/noncanonical shapes keep the MongoDB path, and a PostgreSQL failure never falls back to a successful MongoDB create.
- **Server tests**: removed flag env setup, deleted the flag-off Mongo fallback expectation, made the anonymous contract stores PostgreSQL-only, converted guest-credential coverage into the explicit `TestLegacyMongoGuestResponseOwnershipContract` fixture, and retargeted timed-creation tests at the PostgreSQL HTTP boundary.
- **Configuration**: removed the variable from `compose.yaml`, all `.env.*.example` files, local test/dev env, `e2e/isolated-test-stack.ts`, and the `e2e-ci.yml` matrix field/env forwarding.
- **E2E**: removed the flag-gated skips from the eight formerly opt-in Firefox specs; fixed Firefox-touch response seeding to the explicit-selection `createResponse` contract; converted three Chromium specs to seed owner/guest state through `page.request` instead of legacy localStorage; updated the no-responses layout assertions and stabilized the mobile timezone reset selection. The weekly Firefox group test now seeds and verifies through `page.request` so the browser holds the owner credential.
- **Docs**: `docs/environments.md`, `docs/postgres-staging-rollout.md`, `server/docs/postgres-anonymous-event-compatibility.md`, and `e2e/AGENTS.md` now describe PostgreSQL as the default and no longer instruct flag-based rollback.

- Frontend lint/fmt/typecheck/build/test:unit (1089 tests) pass; E2E lint/fmt/typecheck pass; root Markdown check passes.
- No active references to either retired variable remain outside `backlog/` and `graphify-out/`.

## Risk / follow-up

No source-routing or schema change is outstanding. Noncanonical payload shapes still resolve to MongoDB by design; rollback is now via the migration runbook boundaries rather than an environment variable.
