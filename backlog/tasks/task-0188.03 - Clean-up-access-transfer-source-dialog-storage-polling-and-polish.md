## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Hygiene and polish follow-ups from the TASK-0071.02 review on the source transfer dialog. rememberTransfer appends forever so localStorage grows with every transfer ever created, and the two-second dialog poll issues one status request per saved identifier, multiplying stale traffic as history accumulates. Errors are conflated: every failure in EventAccessTransfer, including clipboard copy, reports the transfer-unavailable message. Transfer states render as raw enum strings, the target page failure alert uses info styling, and granted-access numbering shifts when entries are filtered out.
<!-- SECTION:DESCRIPTION:END -->

<!-- AC:BEGIN -->
