<!-- SECTION:DESCRIPTION:BEGIN -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented PostgreSQL-authoritative folders with explicit legacy-compatible membership.

Schema: migrations/20260910140000_folders.sql adds folders (id UUIDv7, account_user_id, name, color, nullable is_deleted, timestamps) and folder_events (account_user_id, folder_id FK, event_id UUID FK to postgres_events, legacy_event_id TEXT, CHECK exactly one reference populated, per-account unique partial indexes for each reference kind). account_user_id is the legacy external identifier resolved through platform_identities, matching the existing postgres_events owner columns.

Repository: postgres/folders.go adds Folder/FolderMember and CreateFolder, GetFolderByID, ListFolders, UpdateFolder, DeleteFolder, AssignEventToFolder. Every query scopes to account_user_id; missing or foreign folders surface as pgx.ErrNoRows so a caller cannot tell non-existence from another account's folder. DeleteFolder soft-deletes the folder, soft-deletes the account's own PostgreSQL member events, and returns legacy member ids; AssignEventToFolder deletes the account's prior membership for the event before inserting, so one account holds at most one membership per event.

Routes: routes/folders.go uses the repository, treats folder ids as UUIDs, and renders eventIds as canonical public identifiers (bare short_id for PostgreSQL members, m_<shortId|legacy id> for legacy members resolved by one batch Mongo lookup at the route boundary). routes/user.go setEventFolder handles both sources: a PostgreSQL event stores event_id; a legacy MongoDB event resolves its _id and stores legacy_event_id. The old PostgreSQL 422 branch is removed.

Cross-store cleanup: db/folders.go adds GetEventShortIdsByObjectID and MarkOwnedEventsDeleted; folder delete releases the account's owned legacy MongoDB members. postgres/accounts.go deleteAccountAuthority now removes the account's folders (memberships cascade), preserving FR-123 now that folders live in PostgreSQL.

Frontend: Dashboard keys events and matches folder.eventIds by eventPublicId(event); EventItem sends eventPublicId when moving an event to a folder. This replaces the store-specific _id match.

Evidence: routes/postgres_folders_test.go covers CRUD and cross-account isolation, both event sources with duplicate prevention and explicit per-source storage references, and delete cascading to memberships and owned members. account_deletion_test.go now seeds a PostgreSQL folder with a PostgreSQL and a legacy member and asserts both are removed. Dashboard.test.ts asserts canonical grouping across PostgreSQL and legacy events; EventItem.test.ts asserts the canonical eventId sent by the move action.
