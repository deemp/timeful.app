## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Second delivery subtask of TASK-0071, depends on TASK-0071.04. Implement Event Visitor Control Credential (EVCC) generation, hashed persistence, and browser transport as an HttpOnly, SameSite=Lax cookie so the credential value is never available to application JavaScript (TASK-0071 AC #4). Validation only; route-level authorization wiring belongs to the routes subtask.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 EVCCs are generated with crypto/rand and persisted only as hashes, never as plaintext credential values

- [x] #3 EVCC validation uses constant-time comparison and rejects missing, unknown, and revoked credentials; revoked_at is reserved for TASK-0071.02
- [x] #4 Issuance and rotation helpers exist for EVI creation and are reusable by backend route handlers

- [x] #6 Route tests assert cookie flags and that no response body exposes the credential value
