# FR-122: Resolve Retained MongoDB Records To The Authoritative Account

Retained MongoDB records that reference an account shall resolve that reference to the same account identity that the migrated account uses.
The retained records include calendar connections, provider tokens, calendar preferences, friend requests, and historical daily user logs.

A retained document shall not create, merge, rename, or authorize an account, and it shall not act as a second source of account truth.

Automated backend tests demonstrate that a signed-in visitor's retained calendar connections, friend requests, and historical daily logs resolve to the migrated account and that no retained document grants or changes account authority.
