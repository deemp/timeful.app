# FR-122: Resolve Retained MongoDB Records To The Authoritative Account

While a record kind is still retained in MongoDB, a retained record that references an account shall resolve that reference to the same account identity that the migrated account uses.
The retained record kinds are [Calendar Connections](../../../terminology/glossary.md#calendar-connection), provider credentials, calendar preferences, OTP challenges, and historical daily user logs.
Friend requests are retired rather than migrated, so they are not retained.

A retained document shall not create, merge, rename, or authorize an account, and it shall not act as a second source of account truth.
Once a retained record kind is migrated, [FR-121](FR-121.md) governs that kind and this resolution rule no longer applies to it.

Automated backend tests demonstrate that a signed-in visitor's retained calendar connections and historical daily user logs resolve to the migrated account and that no retained document grants or changes account authority.
